# 🏰 Active Directory Enterprise Infrastructure Lab

Design and implementation of a multi-server Active Directory domain environment built on Windows Server 2016 (`labkernel.local`).

## 🚀 Key Highlights
* **Domain Controllers:** DC1 & DC2 replication (`192.168.X.10`, `192.168.X.20`).
* **Services:** AD DS, DNS, DHCP, GPO password policies, OU structure.
* **Clients:** Windows 10 Enterprise joined to domain.
