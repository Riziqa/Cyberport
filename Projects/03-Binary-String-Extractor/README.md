# 🔍 Binary String Extractor & Reverse Engineering Toolkit

Toolkit for automated string extraction and binary inspection during malware triage and reverse engineering.

## 🚀 Features
* Extracts printable ASCII / Unicode strings from raw binary files.
* Regex pattern matching for system calls, actor names, and suspicious function references.

## 🛠️ Usage
```bash
python extract_strings.py <binary_filepath>
```
