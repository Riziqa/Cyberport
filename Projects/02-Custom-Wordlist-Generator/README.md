# 🔑 Custom Wordlist & Combination Generator for Security Auditing

Python utility for generating custom password dictionaries and combination sets for penetration testing and password security audits.

## 🚀 Features
* Generates combinatorial wordlists based on target profile inputs.
* Outputs formatted dictionaries ready for **Hashcat**, **Hydra**, or **John the Ripper**.

## 🛠️ Usage
```bash
python generator.py
```
